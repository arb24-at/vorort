# Bilingual blueprint · Software installation and optimisation

**Review draft, approval pending.** Converts the English v0.1 working draft into a shared EN/DE plan. English source exists; German remains a different legacy composition. This target does not approve or migrate either locale. The unknown German Drive URL is deliberately null; use the verified repository path until a real file link is available.

## Shared brief

Help Berlin private/Homeoffice customers with legitimate supported applications, installation failures, configuration, update conflicts and software-related performance problems. Recognise the request, explain small-job scope and agreed costs before one accessible enquiry, then offer deeper installation/troubleshooting information. Natural English and formal German convey the same planned meaning. No unlicensed software, guaranteed speed, hardware workshop, bypassed access or recovery promises.

`software-en` and `software-de` are **provisional-seed** in `seo-keywords.yml`. Retain these coverage proposals, but Research & SEO must investigate the real gaps before calling them researched. The prior English draft's local language sanity check is not volume evidence. Do not pursue computer-repair, free activation keys or speed-booster intent. Repeated boundaries should be concise and placed where they help a decision.

Target copy can become more compact by removing repeated limits rather than adding new decorative blocks.
